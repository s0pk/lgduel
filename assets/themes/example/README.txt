Example LGDuel theme. All files here are original and released under CC0 (public domain).
Generated by `lgduel --make-example-theme DIR`; edit freely.

To use it: copy this folder to <settings folder>/themes/<name>/ (the settings folder is
%APPDATA%\LGDuel on Windows), then pick <name> in Settings -> Visuals -> Map -> Theme,
or run `lgduel --theme <name>`. After editing files, the console command `reloadtheme` reloads it.
See THEMES.md for every key.
